# Lifting the Corporate Veil

Interactive presentation for Company Law 342 (Prof. Jawahitha Sarabdeen).
Saudi Arabia vs UK company law, 15 minutes, three speakers.

- `index.html`: the web version. Open it in any browser.
- `Corporate_Veil_Presentation.pptx`: the PowerPoint version with speaker notes.

Keys: arrows to move, N notes, T timer, O overview, F fullscreen.

By Eman AlFires, Monerah AlSheikh and Nouran AlQahtani.
